# Technical SEO quality checklist

- [ ] Record HTTP status of the homepage and key routes
- [ ] Compare initial response HTML with hydrated DOM
- [ ] Verify unique page titles, descriptions and canonicals
- [ ] Check Open Graph and social preview tags in the response
- [ ] Verify robots rules and XML sitemap
- [ ] Review internal linking and pagination where applicable
- [ ] Validate any JSON-LD against visible content
- [ ] Check client-side routes on direct navigation and refresh
- [ ] Test keyboard navigation and form labels
- [ ] Measure LCP, CLS and INP with date, device and source
- [ ] Monitor indexing in Google Search Console
- [ ] Report before/after results only with documented evidence
