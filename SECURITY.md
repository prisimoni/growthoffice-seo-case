# Security and privacy

This repository contains only a public technical case study and generalized examples.

It intentionally excludes:
- source code, infrastructure endpoints and configuration copied from the private application;
- `.env` files, keys, tokens and authentication details;
- customer records, personal media and proprietary designs;
- history or commits from the private repository.

Report issues privately to the repository maintainer using GitHub's supported private reporting channel, where enabled.

The source project stays private. If secrets were exposed in its history, removal from the current working tree alone is not sufficient; affected secrets must be assessed and rotated.
